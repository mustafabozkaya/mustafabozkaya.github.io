# Mustafa Bozkaya — Portfolio Site

Personal portfolio built with **React + Vite**.

## 🚀 Quick Start

```bash
npm install
npm run dev        # development server
npm run build      # production build → dist/
```

## 🔄 CI/CD

Push to `main` → GitHub Actions builds → deploys to `gh-pages` branch → GitHub Pages serves live.

## 📁 Structure

```
src/              # React source
public/           # Static assets (images, CV)
.github/workflows # CI/CD pipeline
```
